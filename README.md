# Frontline Map Radar

面向《最终幻想14》国服纷争前线的 Dalamud 插件。在前线战场中显示周围玩家位置，并提供本场名册、标记跟随、局域网第二屏，以及焦点目标的极限技积蓄估算。

适用于 XIVLauncherCN 与 Dalamud。

## 功能

### 大地图玩家点

进入纷争前线并打开大地图后，在地图上叠加敌方玩家位置：

- 红：黑涡团
- 蓝：恒辉队
- 黄：双蛇党

我方玩家使用游戏自带地图标记，插件不再额外绘制。只有已经加载进视野的玩家会出现。

支持的战场包括周边遗迹群（阵地战）、荣誉野（碎冰战）、尘封秘岩（争夺战）、昂萨哈凯尔（竞争战）、沃戈尔·奇尔特（凯旋战）。网页雷达会按当前战场切换对应底图。

### 本场名册与标记

名册记录本场出现过的玩家，包括名字、服务器、阵营、职业、职能，以及已观察到的 PvP 职能技能。

职能技能为每职能三选一。自己的技能可直接读取；其他玩家需要在其咏唱或施放该技能后才会记入。

可为玩家指定 A、B、C、D、1、2、3、4 标记。标记只在本地绘制，并跟随该玩家移动。

### 局域网网页雷达

开启后，同一局域网内的浏览器可以打开第二屏，查看己方、敌方位置、面向、出生点阵营，以及场地标记。默认端口为 17890。网页上可调整底图校准。

### 焦点极限技预测

对当前**焦点目标**估算个人极限槽进度，并在游戏内显示职业、预测百分比、预计充满剩余时间、所用名次，以及死亡暂停、观察到极限技后重置、开战计时等状态。检测到诗人极限技或舞者拂晓舞的加速窗口时，会标明加速中。

这是按职业积蓄时间与前线名次修正做出的时间估算，不能读取他人的真实极限槽。进场前已经积蓄的进度、未观察到的加速效果，以及比分读取失败时的名次，都会影响准确度。比分未知时按第一名（积蓄较慢）估算。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/flradar` | 打开设置 |
| `/flradar roster` | 打开本场玩家名册 |
| `/flroster` | 打开本场玩家名册 |
| `/flradar remote` | 开关局域网网页雷达，并打开设置 |

## 使用

1. 启用插件后进入纷争前线。
2. 按 `M` 打开大地图，查看敌方位置点。
3. 用 `/flroster` 查看名册，并为需要跟踪的玩家指定标记。
4. 将某人设为焦点目标后，可查看其极限技积蓄预测。无焦点时该提示不显示。
5. 需要平板或第二台设备时，在设置中开启「启用局域网网页同步」，用同一网络下的浏览器打开设置里给出的地址。若无法访问，在系统防火墙中放行对应 TCP 端口。

可在设置中调整总开关、点的大小与颜色、是否向网页隐藏本阵营，以及是否显示焦点极限技预测。
